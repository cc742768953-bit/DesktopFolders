# 常见问题

## 启动后没有窗口？

默认就是完整隐藏。点击桌面空白处，或从系统托盘选择“显示分类”。托盘图标可能在右下角的折叠菜单里。

## 为什么点击网页或其他程序的空白处没有展开？

触发区域是 Windows 桌面背景。其他程序的空白区域不属于桌面。

## 可以一直显示吗？

可以，从更多菜单或托盘切换为常驻显示。背景和顶部操作仍随悬停显示。

## 自动隐藏的时间能调吗？

当前公开测试版固定为离开 3 秒后、用 300 毫秒渐隐。图标大小可以直接调整；等待时间与动画时长的界面设置尚未提供。

## 下载源码 ZIP 就能直接运行吗？

GitHub 自动生成的 Source code ZIP 是源码。直接使用请下载 Releases 中名字包含 `windows-x64` 的发布 ZIP；源码需要先执行 `build.ps1`。

## 是真正的 Windows 软件吗？需要什么环境？

是 C# / WPF Windows 桌面程序，目标运行平台是 .NET Framework 4.8。安装了 .NET 8 不代表安装了 Framework 4.8；二者是不同路线。可从微软官方页面安装所需运行环境。

## 原来的桌面文件会被搬走吗？

首次导入只复制快捷方式。添加普通文件或文件夹时保存其路径引用。分类调整不负责移动原文件。

## 为何桌面还有原来的图标？

软件不自动更改系统图标显示设置。可自行通过桌面右键“查看 → 显示桌面图标”选择显示或隐藏原图标。

## 复制到另一台电脑后为什么有些程序打不开？

快捷方式不是软件安装包。目标电脑需要安装对应程序；驱动器、账户和程序路径改变后，需要重新添加入口。内置“此电脑”和管理入口会随程序目录刷新。

## 如何排查问题？

先记录 Windows 版本、屏幕缩放、是否多显示器、是否使用动态壁纸、出现问题的操作步骤。应用目录中的 `app.log` 可辅助排查，但可能包含本地路径；请只分享脱敏后的相关片段。
