# 使用指南

## 第一次运行

解压发布 ZIP，运行 `DesktopFolders.exe`。应用会建立十个默认分类，其中“集合”是所有分类的动态汇总；复制桌面上的 `.lnk` 和 `.url` 后，用名称关键词做一次基础分组。

导入不执行快捷方式，不移动源文件。同名的用户桌面与公共桌面快捷方式优先保留先扫描到的用户桌面项。没有匹配规则的入口归入“系统与效率”，随后可自行调整。

默认启用点击展开：窗口启动后完全隐藏。点击 Windows 桌面空白处，松开鼠标后显示分类；从托盘选择“显示分类”也可以展开。

## 日常操作

1. 点击桌面空白处，显示所有分类。
2. 将鼠标移入分类区域，顶部操作栏和深色背景出现。
3. 点击分类，再点击程序图标启动。
4. 点击界面空白处或桌面空白处，返回所有分类；`Esc` 同样可以返回。
5. 鼠标离开整个分类窗口，等待 3 秒，整个界面用约 0.3 秒渐隐。

点击程序不会主动返回所有分类。窗口自动隐藏后，下次从桌面空白处唤出会回到分类总览。

渐隐期间移回鼠标会恢复显示。正在拖动、展开菜单、管理分类或操作对话框时，不会自动隐藏。等待时间和整窗渐隐时长目前固定，图标大小可直接调节。

## 管理分类与快捷方式

从顶部“管理”、托盘“管理分类”或内置“桌面分类”快捷方式进入。

- 新建分类，改名，用“上移 / 下移”排序。
- 选择一个普通分类，再“添加快捷方式”。支持 `.lnk`、`.url`、程序和普通文件；拖放也可以添加文件或文件夹。
- 使用“移动到…”调整归属，或在展开分类中右键某个入口。
- “移出此分类”会把入口转入“未分类”，保留文件；移除整个分类时，其入口同样转入“未分类”。
- “集合”是动态汇总，不能像普通分类那样直接添加内容。

添加 `.lnk` / `.url` 时会复制一份到应用的 `Shortcuts/`。其他文件和目录采用原路径引用，因此外部文件移动后，需要更新入口。

## 图标、位置与显示模式

“更多 → 图标大小…”提供 32–64 像素的滑块。分类预览采用实际图标大小的 75%，用于保持卡片紧凑。拖动即时预览，取消恢复原值，保存才写入配置。

位置未锁定时，拖动“桌面分类”标题移动整个窗口。在更多菜单中锁定位置或恢复默认位置。

更多菜单或托盘可以切换“点击展开 / 常驻显示”。常驻显示保留图标与分类名，背景和顶部操作依然随悬停变化。

## 搜索、备份与退出

点击顶部搜索按钮或使用 `Ctrl+F`。搜索覆盖全部分类，并按名称包含关系筛选。

从更多菜单导出 JSON 配置。配置包含本地路径；完整迁移时请同时保留 `Shortcuts/` 文件夹。不要把包含个人路径的配置或完整日志直接贴到公开 Issue。

右键托盘选择“退出”才会结束程序。窗口的关闭操作会将组件隐藏，仍可从托盘恢复。

## 安装与开机启动

可以直接使用便携目录；需要桌面和开始菜单快捷方式时，运行发布包内的 `Install.cmd`。

高级用法：

```powershell
.\Install.ps1 -InstallDirectory 'D:\Apps\DesktopFolders'
.\Install.ps1 -InstallDirectory 'D:\Apps\DesktopFolders' -StartWithWindows
```

开机启动采用当前用户启动文件夹中的快捷方式，不创建系统服务。后续想关闭开机启动，可从系统“启动应用”管理，或移除该启动快捷方式。

更新时先从托盘退出，再运行新发布包的安装脚本，选择相同目录；现有配置和 `Shortcuts/` 会保留。
