# 桌面分类 v0.1.0-beta.1

首个公开测试版：一个简单、透明、可自动隐藏的 Windows 桌面快捷方式分类工具。

**需要时出现，平时让出桌面。**

## 主要功能

- 桌面空白处点击展开分类，移入显示深色背景和顶部操作。
- 移出窗口等待 3 秒，整个窗口用 300 毫秒渐隐；移回可取消。
- 分类预览、展开、搜索、拖放添加、图标大小、位置锁定。
- 启动程序保留当前分类，点击空白返回分类总览。
- 首次运行复制桌面快捷方式并做基础分组，原文件保留。
- 此电脑、管理入口、托盘、常驻模式、配置备份和恢复。

## 下载

下载 `DesktopFolders-v0.1.0-beta.1-windows-x64.zip`，完整解压后运行 `DesktopFolders.exe`。GitHub 自动生成的 Source code ZIP 是源码，不是可直接运行的发布包。

需要创建桌面和开始菜单入口时，运行包内 `Install.cmd`。自定义目录、开机启动以及迁移说明见项目使用指南。

运行要求：Windows x64，.NET Framework 4.8 或更高版本。程序使用普通用户权限，应用目录需要可写。

附带 `.sha256` 文件，可用于核对 ZIP 的完整性。发布包不包含作者的分类配置、快捷方式、图标缓存、日志或历史备份。
